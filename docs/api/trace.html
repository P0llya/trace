query Parameters

integer >= 1

limit
integer [ 1 .. 50 ]
Default: 20
Example: limit=20

Загрузить артефакт(ы) в коллекцию

Поддерживает два режима:

  • multipart/form-data с полем "file" - загрузка файла (JPG/PNG/GIF/TXT)
  • application/json с полем "content" - добавление текстовой цитаты без файла
Authorizations:
bearerAuth
path Parameters
collectionId
required
string <uuid>
Request Body schema:
required
file
required
string <binary>

Файл JPG/PNG/GIF/TXT, максимум 25 МБ

name
string or null <= 255 characters

Название артефакта. Если не указано - берется имя файла без расширения

tags
Array of strings <= 20 items [ items <= 50 characters ]

Теги (передаются как повторяющиеся поля: tags[]=мемы&tags[]=котики)

Responses

Production

https://api.trace.app/api/v1/collections/{collectionId}/artifacts
