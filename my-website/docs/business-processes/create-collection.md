# BPMN-диаграмма: создание новой коллекции

## Диаграмма процесса

```plantuml
@startuml
|Пользователь|
start
:Нажать "Создать коллекцию";
|Система|
:Отобразить форму;
|Пользователь|
:Ввести название, описание, обложку;
:Нажать "Сохранить";
|Системя|
:Валидировать название (DMN);
if (Название заполнено?) then (Да)
  :Сохранить коллекцию в БД;
  :Перенаправить на страницу коллекции;
  stop
else (Нет)
  :Показать ошибку "Название обязательно";
  :Вернуться к форме;
endif
@enduml
```

## DMN-таблица валидации названия

| Название заполнено? | Длина > 0 | Результат | Описание |
|---------------------|-----------|-----------|----------|
| true | true | "valid" | Название корректно |
| false | false | "invalid_empty" | Ошибка: поле пустое |

Политика: UNIQUE — только одно правило может сработать.

## Детали процесса

1. **Инициация** – пользователь нажимает кнопку.
2. **Отображение формы** – система показывает поля: Название (обязательное), Описание (опционально), Обложка (опционально).
3. **Ввод данных** – пользователь заполняет.
4. **Валидация** – проверка через DMN:
   - Если название пустое → ошибка, возврат к форме.
   - Если название введено → переход к сохранению.
5. **Сохранение** – запись в БД, привязка к пользователю.
6. **Завершение** – редирект на страницу созданной коллекции.

Событие «Коллекция создана» наступает только при успешной валидации.
