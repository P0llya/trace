# Добро пожаловать в Trace

**Trace** — веб-платформа для создания личных цифровых коллекций, вдохновленная эстетикой скрапбукинга. Это приватное пространство, где пользователь собирает артефакты цифровой жизни (скриншоты, мемы, фото, голосовые сообщения, цитаты), объединяет их в коллекции по темам и настроениям и пересматривает как «капсулы времени».

## Ценность для пользователя

> *Цифровой хаос превращается в осмысленную, красивую и легко доступную историю жизни.*

## Версия MVP (1.0)

- Регистрация и авторизация
- Создание коллекций
- Загрузка изображений (JPG, PNG, GIF) и текста
- Добавление тегов и описаний
- Приватность по умолчанию
